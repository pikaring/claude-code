# ねこの ともだち（高齢者向け ねこのおせわ＆脳トレ）

ブラウザだけで動く、たまごっち風の「猫のお世話ゲーム」です。
バックエンドは使わず、セーブデータは LocalStorage に保存します。

## ファイル
| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造（ヘッダー／部屋／ボタン／クイズ） |
| `style.css` | 大きなUI・高コントラスト・アニメーション |
| `main.js` | ゲームロジック・LocalStorage・時間判定・クイズ制御 |

## 遊び方
1. `index.html` をブラウザで開く（GitHub Pages の場合は `/neko-game/`）。
2. 「なでる」で なかよし度 +1、「ごはんを あげる（クイズ）」の正解で +3。
3. なかよし度 10 / 30 / 50 / 80 で部屋にアイテムが増えます。

## 設計上の約束
- 操作はシングルタップのみ（スワイプ・長押し・ドラッグは不使用）
- 制限時間・ゲームオーバー・病気・死亡は一切なし
- 久しぶりに開くと「まってたニャ！」と迎える
- 不正解でもペナルティなし（「おしい！もういっかい！」で再挑戦）

## 画像への差し替え
猫・部屋はCSSクラスを分けてあります。`style.css` の
`.cat--image` / `.room--image` のコメントを外し、`images/` に画像を置いて
`index.html` の `class="cat"` を `class="cat cat--image"` にすれば差し替えできます。
