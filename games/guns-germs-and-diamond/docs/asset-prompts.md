# カードの絵を画像生成AI（Gemini）で作るときのプロンプト

5種類のカード（病原菌・偵察兵・兵士2・兵士3・兵士4）を **1枚のグリッド画像** としてまとめて
出させます。1枚にまとめると画風がそろい、あとから切り分けられます。

- 並び順は **左上から右へ、次の行** の順（3列 × 2行、6コマ目は空き）
- 切り出し後のファイル名は `app/images/card-*.png`
- `app/index.html` の `CARD_TYPES` が読みこみます。画像が無ければ文字表示のままで遊べます

| コマ | 中身 | ファイル名 |
| --- | --- | --- |
| 1（左上） | 病原菌（0） | `card-germ.png` |
| 2 | 偵察兵（1） | `card-scout.png` |
| 3（右上） | 兵士・階級低（2） | `card-soldier2.png` |
| 4（左下） | 兵士・階級中（3） | `card-soldier3.png` |
| 5 | 兵士・階級高（4） | `card-soldier4.png` |
| 6（右下） | 空き（背景のみ） | — |

## プロンプト（そのまま貼る）

```
カードゲーム用のキャラクターイラストを、1枚の画像にまとめたグリッド形式で描いてください。

【全体の形式】
・3列 × 2行、合計6コマの均等なグリッド（各コマは正方形、1コマあたり512×512px相当）
・コマの区切りは細い線で明確に。コマ内にキャラクターを1体ずつ、中央に配置
・キャラクターは上半身のバストアップ。コマの枠からはみ出さない
・背景は各コマとも「無地の単色（明るいグレー #d8d8d8）」で、影や模様を入れない（後で背景を透過処理します）
・文字・数字・記号・ロゴは一切描かない（ゲーム側で数字を重ねます）
・6コマすべて同じ画風・同じ線幅・同じ塗り・同じ光源で、シリーズものとして統一する

【画風】
・レトロなボードゲームのカード絵のような、手描き感のあるフラットイラスト
・太めの均一な輪郭線、影は1段だけのシンプルな塗り、色数は少なめ
・かわいすぎず、劇画すぎない中間のトーン。ダイヤモンド鉱山を舞台にした冒険譚の雰囲気
・配色は全体を通して、くすんだ青緑・カーキ・砂色・錆色を基調にする

【各コマの中身】（左上から右へ、その次の行へ）
1コマ目：病原菌。緑色の球状の微生物のキャラクター。表面にトゲとブツブツ、目が2つで不気味だがコミカル。半透明の飛沫やモヤを薄くまとわせる。兵士とは明確に別カテゴリに見える異形の存在
2コマ目：偵察兵。軽装の若い斥候。双眼鏡を目に当てている、または首から下げている。帽子とマフラー、背中に小さな背嚢。銃は持たず身軽。表情は用心深い
3コマ目：兵士（新兵）。素朴な平鍋型ヘルメット、色あせた軍服、シンプルな小銃を肩に担ぐ。階級章はなし。やや不安げで頼りない顔
4コマ目：兵士（軍曹）。しっかりしたヘルメット、胸に弾帯、袖に山形の階級章2本、丈夫なライフルを構える。歴戦の落ち着いた表情、頬に小さな傷
5コマ目：兵士（将校）。つばのある軍帽、肩章とコート、片手に指揮棒か拳銃。胸に勲章。威圧感のある堂々とした立ち姿。3コマの兵士のうち最も強そうに見せる
6コマ目：キャラクターを描かず、背景の単色のみ（空きコマ）

【重要】
・3コマ目→4コマ目→5コマ目の順に、装備が豪華になり「強そうに」見える序列をつけてください
・6コマとも同一人物に見えないよう、顔と装備ではっきり描き分けてください
```

## 切り分け

`cat-on-escape` の `tools/make_face.py` と同じ手順が使えます（背景除去・正方形化・512px化・
グリッド切り分け）。並び順を上の表どおりに指定してください。

```
python3 tools/make_face.py app/images grid.png:card-germ,card-scout,card-soldier2,card-soldier3,card-soldier4
```
