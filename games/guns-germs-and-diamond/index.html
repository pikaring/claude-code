伏せた1枚で、
鉱山ごと奪う。

産出量の違う5つの鉱山に、同じ5枚の手札から1枚ずつ伏せて置く。 大隊は兵士に勝ち、病原菌はほとんどの札と引き分け、その病原菌に偵察兵だけが勝つ。 引き分けた鉱山は次のラウンドへ積み増され、終盤ほど1枚の重みが増していきます。

どんなゲーム

三すくみの5枚を、5つの鉱山へ。

手札は毎ラウンド 0〜4 の5枚に戻ります。強い札をどの鉱山に置くか、 それだけを決める10分のゲームです。

01

大隊 > 偵察兵 > 病原菌 > …

数字が大きい方が勝つ、ふつうの強弱。ただし 病原菌（0） は兵士の誰とも引き分け、 その病原菌に 偵察兵（1） だけが勝ちます。

  • 0 病原菌 Germs：1以外の全カードと引き分け
  • 1 偵察兵 Scout：病原菌に勝ち、兵士に負ける
  • 2 コマンドー／3 騎兵隊／4 大隊：大きい方が勝ち
02

鉱山は毎ラウンド 復活する

取られた鉱山には、次のラウンドに同じ産出量の鉱山カードが1枚 配り直されます。 💎5の鉱山を取っても、そこは次もまた💎5です。

  • 5つの鉱山は左から 💎1・2・3・4・5
  • 盤から鉱山が消えることはない
03

引き分けは 積み増される

引き分けた鉱山はカードが積み重なり、次のラウンドにもう1枚 配られます。 💎4の鉱山が引き分けなら、次は💎4が2枚で 8点。

  • 病原菌で止めた山が、そのまま自分の狙い目にもなる
  • 3ラウンド目まで引き分けた山は、誰の手にも渡らない
04

同じ手札、同じ盤面

お互いの手札はまったく同じ。運の差はなく、相手がどの山に何を置くか の読み合いだけが残ります。

  • 自分の札は表向き、相手の札だけ伏せて進む
  • 決めた瞬間に左から順にオープン

あそびかた

手札をクリックするだけ。

1手札のカードをクリックすると、左の鉱山から順に置かれる
2置きなおしたいときは、その鉱山をクリックすると手札に戻る
35つ置いたら「これで決める」。そのまま左から順にオープン
4強い札を出した方がダイヤモンドを獲得。鉱山の上に WIN / LOSE / DRAW が出る
5引き分けた鉱山は積み増されて次のラウンドへ。全3ラウンドで決着

パソコンではクリック、スマホ・タブレットではタップで遊べます。

対戦相手

All in TEXAS と同じ5人が、卓の向こうに座る。

同じ作者のテキサスホールデム All in TEXAS と共通の5人です。「堅さ・攻め・仕掛け」の3つの値をこのゲーム用に読み替えているので、 同じ盤面でも相手によって置き方が変わります。

堅実

ビエホ

山の価値どおりに、強い札から順に置いてくる。仕掛けはほとんどしないぶん、取りこぼしも少ない。

攻撃

ディアブロ

一番大きい山を大隊でもぎ取りに来る。病原菌で止める仕掛けも多く、大きい山ほど荒れる。

ゆるい

ゴルド

置き場がばらける。安い山に大隊が来ることもあり、噛み合うと思わぬ失点になる。

標準

ヴィニー

教科書どおり。おいしい山を病原菌で止め、そこへ偵察兵を合わせてくる。

気まぐれ

ロコ

同じ場面でも置き方が変わる。読み切れないぶん、こちらの仕掛けも通りやすい。

むずかしさ

やさしい／ふつう／むずかしい

やさしい は鉱山ごとに「相手が何を置いてきそうか」の予想と理由が出ます。 むずかしい は相手があなたの前ラウンドの置き方まで読んできます。

つくり

HTML / CSS / JavaScript だけ。

フレームワークもビルドも使っていません。app/index.html を開けばそのまま動きます。 カードの絵は1か所にまとめてあり、読みこめたときだけ使われます。

絵の 差しかえ口app/index.html の CARD_TYPES に画像のパスを書くだけ。読みこめないときは数字だけで遊べます。
相手の 思考planAssignment() ひとつ。やさしいモードの予想は、同じ関数を乱数なしで走らせた結果です。
保存何も保存しません。サーバーにも何も送りません。
カードの絵画像生成AIに1枚のグリッドで描かせ、tools/make_cards.py で切り分け・背景透過・512px化しています。

よくある質問

気になるところ

お金は かかりますか？

かかりません。無料で、広告も課金もありません。

インストールは 必要ですか？

不要です。ブラウザで開くだけ。ホーム画面に追加すると、アプリのように全画面で開けます。

データは どこかに 送られますか？

送られません。得点も設定も、その場かぎりで保存すらしていません。

病原菌は 強いのですか？

勝てませんが、ほとんど負けません。偵察兵にだけ負け、兵士とはすべて引き分けます。相手に取らせたくない鉱山へ置いて、積み増して仕切り直すための札です。

引き分けた鉱山は どうなりますか？

カードが積み重なり、次のラウンドにもう1枚配られます。💎4の鉱山が引き分けなら、次のラウンドは💎4が2枚で8点になります。3ラウンド目まで決着しなければ、どちらの手にも渡りません。

2人で 対戦できますか？

いまはCPU対戦のみです。相手は5人から選べ、むずかしさも3段階あります。

原作は どこで 買えますか？

アナログ版は、いそのたかみ氏（鷹巣堂）がゲームマーケット2020春で発表したカードゲームです。くわしくは鷹巣堂のブログをご覧ください。
