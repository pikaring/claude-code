# ことば穴うめパズル(四字熟語・ことわざ)

高齢者向けの、アクション性のないことばパズル。**スマートフォンを横向き**にして遊ぶ
前提で、1画面に収まる大きな文字だけで完結する。

`games/kotoba-anaume/index.html` をブラウザで開けば動く。サーバもビルドも外部
ライブラリも不要(`index.html` と `questions.js` の2ファイルだけ)。

## 遊び方

1問ごとに「一石□鳥」「棚から□」のように1か所が空欄になっている。下に並ぶ
4つのタイルから、当てはまることばをタップする。全10問。

- **時間制限なし・減点なし**。間違えたタイルには ✕ が付き、何度でも選び直せる
- 正解すると読みと意味を大きな文字で表示し、「つぎへ」で次の問題へ進む
- 「ヒント」で選択肢を2つに絞れる(1問1回)
- 上部の帯が進み具合。一度で正解した問題は緑、選び直した問題は黄色
- 「♪音あり/音なし」で効果音を切り替え(音が出せない端末では自動的に無効)
- 最後に「一度で正解した数」を★で表示。順位や記録は残さない

## 高齢者向けに意図した設計

| 項目 | 方針 |
|---|---|
| 操作 | **タップのみ**。ドラッグ&ドロップは指が離れて失敗しやすいため使わない |
| 文字の大きさ | 画面の高さ・幅に比例(`clamp` + はみ出し時の自動縮小)。横向きスマホで問題文は約58〜70px |
| 画面構成 | `100dvh` に収めスクロールなし。1画面1タスク |
| タップ領域 | 選択肢タイルは高さ54px以上、横並び4つで指の届く下半分に配置 |
| 失敗の扱い | ペナルティ・時間切れ・ゲームオーバーなし。「おしい!もう一度」だけ |
| 色 | 本文コントラスト比 15:1 以上。正誤は色に加えて ○ / ✕ の記号でも示す |
| その他 | ピンチズーム可(`user-scalable` を止めていない)、セーフエリア対応、`prefers-reduced-motion` 対応 |

縦向きのときは「横向きにしてください」の案内を出すが、「このまま あそぶ」で
そのまま遊ぶこともできる(2×2で選択肢が並ぶ)。

## 問題の追加・変更

`questions.js` の `QUESTIONS` 配列に足すだけ。全36問から毎回10問をランダムに出題する。

```js
{ t:"k",                       // "y"=四字熟語 / "k"=ことわざ(見出しの表示が変わる)
  q:"猿も_から落ちる",          // "_" が空欄の位置
  a:"木",                      // 正解
  c:["木","枝","山","屋根"],    // 選択肢4つ(正解を含む。表示順はシャッフルされる)
  yomi:"さるも きからおちる",
  imi:"どんな名人でも、ときには失敗することがある。" }
```

選択肢は4つ前提(タイルが横1列に並ぶ)。増やすと横向きスマホでは文字が小さく
なるため、増やす場合は `.choices` の `grid-template-columns` も調整する。

## 動作確認

Playwright で横向き844×390 / 667×375、タブレット1024×600、縦向き390×844 の
4サイズについて、縦横スクロールが発生しないこと・文字がタイルからはみ出さないこと・
1問の正誤〜結果画面まで進めること・JSエラーが出ないことを確認済み。
