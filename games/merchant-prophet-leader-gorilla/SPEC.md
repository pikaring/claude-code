# 商人・預言者・指導者・ゴリラ — ルールと仕様（案 v0.2）

ジャレド・ダイアモンド『商人・預言者・指導者・王 リーダーは本当に歴史を動かすのか』
（土方奈美 訳、日経BP、2026年10月刊）をもとにした、2〜5人用のトリックテイキング。
**普通のトランプ1組で、オフラインでも遊べる**ようにしてある。

シリーズの題の付け方をそのまま使う。

| 原題 | ゲーム | 差し替えた語 |
| --- | --- | --- |
| 第三のチンパンジー | 第三のゴリラ | チンパンジー → ゴリラ |
| 銃・病原菌・鉄 | 銃・病原菌・ダイヤモンド | 鉄 → ダイヤモンド |
| 商人・預言者・指導者・王 | **商人・預言者・指導者・ゴリラ** | 王 → ゴリラ |

リポジトリ名の案は `merchant-prophet-leader-gorilla`。王は役割として残るが、
題では王の座にゴリラが座る。本の問い「リーダーは本当に歴史を動かすのか」への
このゲームなりの答えは、**リーダーは自分の関心（スート）しか動かせず、
ゴリラ（成り行き）は何でも根こそぎ持っていく**、というもの。

### v0.1 からの変更

- ゴリラは **取った札の数字をすべて足す**（破壊的に強くてよい。1枚3点の案はやめた）
- **得点になった札は取った人の得点札になり、ゲームに戻らない**。局を重ねるほど山札が痩せる
- 札が足りなくなるので、40枚からトランプ52枚に増やした（2人だけは40枚）
- 局数は固定をやめ、**配れなくなったら終わり** にした

## 1. 札 — トランプ1組

- 3〜5人は **52枚**（A〜K）、2人は絵札を抜いた **40枚**（A〜10）
- 数字がそのまま強さと点。**A=1（いちばん弱い）**、J=11、Q=12、K=13
- ジョーカーは札としては使わない（オフラインではゴリラの役割カードにする）
- **切り札スートはない**

スートは4つの役割に1つずつ対応する。
トランプのスートを中世の身分に当てはめる昔からの俗説
（♠貴族・軍人、♥聖職者、♦商人、♣農民）にならった。

| スート | 役割 | 読み |
| --- | --- | --- |
| ♦ ダイヤ | 商人 | 貨幣 |
| ♥ ハート | 預言者 | 信仰 |
| ♣ クラブ | 指導者 | 民衆（民衆を率いる者） |
| ♠ スペード | 王 | 剣 |

**ゴリラには対応するスートがない。**

## 2. 役割と円卓

- 役割は **商人・預言者・指導者・王・ゴリラ** の5つ
- 役割は5つの席をもつ **円卓** に置かれている。プレイヤーは席1から時計回りに着き、
  5人未満なら残りは **空席**
- **1トリックごとに、役割が時計回りに隣の席へ移る**
- 1局は **5トリック**。円卓がちょうど1周するので、人数にかかわらず
  **1局の中で全員が各役割を最大1回ずつ担い、ゴリラになるのは1人1回だけ**
  （2〜4人では、空席にいるあいだの役割は担わない）
- 空席にある役割のスートは、そのトリックでは **だれのものでもない**
- 役割の予定はすべて公開。誰がいつ何になるかは、局の最初から全員に見えている

プレイヤー p（0始まり）のトリック t（0始まり）での役割は
`役割[(p − t + 局番号) mod 5]`（役割の並び: 0商人 1預言者 2指導者 3王 4ゴリラ、局番号は0始まり）。

### 例：5人・第1局

| | T1 | T2 | T3 | T4 | T5 |
| --- | --- | --- | --- | --- | --- |
| P1 | 商人 | **ゴリラ** | 王 | 指導者 | 預言者 |
| P2 | 預言者 | 商人 | **ゴリラ** | 王 | 指導者 |
| P3 | 指導者 | 預言者 | 商人 | **ゴリラ** | 王 |
| P4 | 王 | 指導者 | 預言者 | 商人 | **ゴリラ** |
| P5 | **ゴリラ** | 王 | 指導者 | 預言者 | 商人 |

### 例：3人・第1局（席4・5は空席）

| | T1 | T2 | T3 | T4 | T5 |
| --- | --- | --- | --- | --- | --- |
| P1 | 商人 | **ゴリラ** | 王 | 指導者 | 預言者 |
| P2 | 預言者 | 商人 | **ゴリラ** | 王 | 指導者 |
| P3 | 指導者 | 預言者 | 商人 | **ゴリラ** | 王 |
| 空席 | 王・ゴリラ | 指導者・王 | 預言者・指導者 | 商人・預言者 | 商人・ゴリラ |

T1とT5はゴリラが空席にいるので、そのトリックにゴリラはいない。

### オフラインでの役割カード

役割カードを5枚用意する（ジョーカー1枚をゴリラにし、ほかは紙に書くか、
使わない札で代用する）。人数分を各プレイヤーの前に、残りを
**最後のプレイヤーと最初のプレイヤーのあいだの「空席」** に並べる。
トリックが終わるたびに、全員（空席を含む）が自分の前の役割カードを左隣へ送る。

## 3. 準備（1局ごと）

1. 山札をシャッフルする
2. 配る枚数は **8枚、ただし山札が足りなければ「山札の枚数 ÷ 人数」（切り捨て）**
3. **配る枚数が5枚未満になるなら、ゲームは終わり**（→ 第6節）
4. 配り切れなかった札は伏せたまま使わない
5. 局番号に従って役割を置く

配った札のうち **5枚しか出さない**（8枚配った局なら3枚残る）。
先の役割の予定が見えているので、「T4で王になるから♠Kは取っておく」
「T3のゴリラに備えて強い札を残す」のように、どの札をどのトリックに使うかの計画が中心になる。

## 4. トリック

- 第1トリックのリードはその局の **親**。以降は前のトリックの勝者がリードする
- 親は第1局がP1、以降は局ごとに時計回りに移る
- **マストフォロー**：リードされたスートを持っていれば必ず出す。なければ何を出してもよい
- **リードされたスートでいちばん大きい数字** を出した人がトリックを取る（同じ札はないので同点はない）

## 5. 得点と札のゆくえ

トリックを取った人は、**そのトリックでの自分の役割** に応じて札を得点札にする。

| 役割 | 得点札にする札 |
| --- | --- |
| 商人・預言者・指導者・王 | トリックの中の **自分のスートの札だけ** |
| ゴリラ | トリックの中の **札すべて**（スートは関係ない） |

- 得点札は自分の前に表向きに置き、**ゲームが終わるまで山札に戻らない**
- 得点札にならなかった札（取った人のスート以外の札、だれも取らなかった札）は捨て札になる
- 局の終わりに、捨て札と手に残った札と配り切れなかった札をまとめて山札に戻す
- 得点は **得点札の数字の合計**（A=1 … K=13）

ゴリラに取られると、その場の札がまるごと得点になり、しかも山札から消える。
ほかのプレイヤーは、ゴリラの番の前に高い札を別のトリックで出し切ってしまうか、
ゴリラに勝てる強い札を取っておくかを選ぶことになる。

## 6. 決着

- 局の準備で **配る枚数が5枚未満になったら** ゲームは終わる
- 得点札の数字の合計がいちばん多い人の勝ち。同点は引き分け

局数は決まっていない。ゴリラや役割のスートが札を持っていくほど山札は早く痩せ、歴史は早く終わる。

### 簡易シミュレーション（`tools/sim_balance.py`、各3000ゲーム）

| 人数 | 札 | 局数の平均（最短〜最長） | ゴリラの点の割合 | 1人あたりの合計点 |
| --- | --- | --- | --- | --- |
| 2人 | 40枚 | 5.7（4〜8） | 45% | 95 |
| 3人 | 52枚 | 5.4（3〜9） | 54% | 98 |
| 4人 | 52枚 | 4.0（2〜8） | 60% | 66 |
| 5人 | 52枚 | 3.0（2〜7） | 62% | 46 |

40枚のままだと5人で平均2.0局（最短1局）、4人で2.8局しかもたないので、3人以上は52枚にした。
2人で52枚だと平均7.7局と長いので、2人は40枚。

## 7. 曖昧になりやすい点

- 「ターン」は1トリックのこと。役割は **トリックごと** に移る（局ごとではない）
- 役割は取ったトリックの **その時点の** 役割で数える
- 1局の中でゴリラになるのは1人1回だけ。2〜4人では、だれもゴリラでないトリックがある
- 役割のスートの札でも、**トリックを取らなければ** 得点札にはならない
- 空席の役割のスートの札は、ゴリラ以外にはだれも得点札にできない
- リードする人は自分のスートを出す必要はない
- 手に残った札は公開しない。局の終わりに山札へ戻す

## 8. 数値まとめ

| 項目 | 値 |
| --- | --- |
| 人数 | 2〜5人 |
| 札 | 3〜5人 52枚（A〜K）／2人 40枚（A〜10） |
| 札の強さと点 | A=1 … K=13 |
| 配る枚数 | 8枚（足りなければ 山札÷人数、5枚未満で終了） |
| 1局のトリック数 | 5（役割の円卓がちょうど1周） |
| 役割 | 5（商人・預言者・指導者・王・ゴリラ） |
| スートの役割が取るもの | 取ったトリックの自分のスートの札 |
| ゴリラが取るもの | 取ったトリックの札すべて |
| 得点札 | ゲームに戻らない。数字の合計が得点 |
| 終了 | 配る枚数が5枚未満になったとき |

## 9. アプリの仕様

作りは `guns-germs-and-diamond/CLAUDE.md` のツール群共通の規約と、
`gorilla-gorilla-gorilla` にそろえる。

### 9-1. 構成

    index.html                  紹介ページ（hero → specs → goods → about → howto → make → faq → cta → family → footer）
    app/index.html              ゲーム本体。HTML/CSS/JSを1ファイルに（ビルドなし・外部依存なし）
    assets/site.css             共通デザイン。アクセント色だけ変える（案：王の紫 #6b4a9e）
    assets/icon.png / favicon.png
    assets/goods.json           本の画像と価格（fetch_goods.py＋毎日3:00 JSTのワークフロー）
    img/1.png〜9.png            役割5枚＋スートの印4枚＝3x3グリッド1枚から切り分ける
    img/PROMPT.md               そのグリッドのプロンプト
    tools/split_grid.py         gorilla-gorilla-gorilla のものを流用
    tools/sim_balance.py        バランス確認用のシミュレーション
    RULES.md                    上の第1〜8節（実装の挙動と一致させる）
    sitemap.xml                 紹介ページと app/ の2本

- 本の棚には本書を載せる。ASIN は Amazon の商品ページで見えた `4296118587` だが、
  規約どおり Creators API の `searchItems` で実在を確かめてから載せる。
  既刊2作（第三のチンパンジー、銃・病原菌・鉄）も並べてシリーズとしてつなぐ
- 紹介ページに **「トランプで遊ぶ」** の節を置き、オフラインの遊び方（役割カードの作り方と回し方）を載せる
- GA4（`G-3FCFQY4W85`）は紹介ページだけ。JSON-LD・canonical・OG も規約どおり
- ゲーム画面にはクレジットや紹介文を出さない

### 9-2. 対戦

- **あなた＋CPU 1〜4人**（開始時に人数を選ぶ。既定は5人）。札の枚数は人数で自動的に決まる
- CPUは all-in-texas の `PERSONAS` と同じ5人（ビエホ／ディアブロ／ゴルド／ヴィニー／ロコ）から
  人数ぶん選ぶ。`tight` / `aggr` / `bluff` の読み替えは次のとおり

| 値 | このゲームでの意味 |
| --- | --- |
| `tight` | 先の役割（とくにゴリラ）のために強い札を取っておく度合い |
| `aggr` | ゴリラのトリックを取りに行く・止めに行く強さ |
| `bluff` | ゴリラの番の前に高い札を捨てて逃がす、自分のスートでないスートをリードする、などの頻度 |

- むずかしさ：やさしい（CPUのぶれが大きい。出せる札のうち得になるものに印を出す）／
  ふつう／むずかしい（出た札と得点札を覚え、残りの強い札を読む）

### 9-3. CPUの思考（シミュレーションで使ったものを土台にする）

各候補札について次の和が最大のものを出す。

- **取り分** — その札で勝つなら、今の役割で得点札になる数字の合計
- **妨害** — 今勝っている人の得点を消せるなら、その点の一部（ゴリラが勝ちそうなときは強く止める）
- **温存** — 先のトリックで自分のスートになる札・ゴリラの番で勝つための強い札を出すことの損
- **献上** — 負けるときに、勝つ人の得点札になる札（その人のスート、ゴリラなら何でも）を出す損

むずかしさと人物の値で、各項の重みと乱数の幅を変える。

### 9-4. 画面

- 緑のラシャの卓。中央に **円卓**（5つの席と役割の札）。トリックのたびに円卓が回る演出
- **役割表**（プレイヤー × 5トリック）を常に出し、今のトリックの列を強調する。
  このゲームでいちばん大事な情報なので、スマートフォンでも省かない
- 各プレイヤーの席に、今の役割のアイコンと「このトリックで得点札になる札」（スートの印、ゴリラなら全部）を出す
- 各プレイヤーの得点札をスートごとに重ねて出し、合計点を添える
- **山札の残り枚数** と「次の局に配れる枚数」を出す（あと何局もつかが読める）
- ノートPC（1000×760）とスマートフォン（390×780）で縦スクロールなし
- 札の絵がなくても印と数字だけで遊べる（絵は読み込めたときだけ使う）

## 10. 決めたいこと（確認待ち）

1. **切り札**：いまは切り札スートがない。「切り札を取っておく」は、ゴリラに勝つための
   強い札を残すことと読んだ。本当に切り札スートを入れたいなら、たとえば
   「王の役割の人がいるトリックでは♠が切り札」のような形が考えられる
2. **Aの扱い**：A=1（最弱）にした。トランプに慣れた人はAを最強と思いがちなので、
   A=14（最強・14点）にする手もある
3. **8枚配って5枚出す**：残りの3枚は山札に戻る。配る枚数の上限を変えると局数が変わる
4. **役割ごとの特殊能力**：いまはない。まずは能力なしで作り、遊んでから足したい
5. **リポジトリ名**：`merchant-prophet-leader-gorilla` でよいか
