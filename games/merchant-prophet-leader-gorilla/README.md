# 商人・預言者・指導者・ゴリラ

リーダーは、歴史を動かすのか。

商人・預言者・指導者・王・ゴリラの5つの役割が1トリックごとに隣の席へ回る、
2〜5人用（あなた＋CPU）のトリックテイキング。
ブラウザだけで動く（ビルドなし、外部依存はGoogle Fontsのみ、通信なし）。

**あそぶ → https://pikaring.github.io/merchant-prophet-leader-gorilla/** （公開後）

題はジャレド・ダイアモンド『商人・預言者・指導者・王 リーダーは本当に歴史を動かすのか』
（土方奈美 訳、日経BP）の「王」をゴリラに差し替えたもの。
「第三のチンパンジー → 第三のゴリラ」「銃・病原菌・鉄 → 銃・病原菌・ダイヤモンド」に続くシリーズ3作目。
ルールはオリジナル。

## ルールの要点

くわしくは [`SPEC.md`](SPEC.md)（第1〜9節がルール、第10節が印刷）。
**アプリはまだ v0.8（王＝献上と下賜、預言＝取る人を当てる、バナナ・ゴリラ札なし）で動いている。**

- 札は4スート（貨幣・聖典・旗・冠）で、同じ数字が2枚ずつ。数字がそのまま強さと点。人数で数字の範囲を変える
  （2人1〜7／3人1〜9／4人1〜11／5人1〜13）。5人ならトランプ2組と同じ104枚
- 役割は5つ。商人＝貨幣、預言者＝聖典、指導者＝旗、王＝冠が、取ったトリックの**自分のスートの札だけ**を得点札にする。
  **ゴリラは全部**
- 役割は**1トリックごとに時計回りに隣へ**。1局5トリックで円卓が1周するので、ゴリラは1局に1人1回
- リードだけは **連番**（同じスートの続き数字2〜3枚）や **同数**（同じ数字2〜3枚）を重ねて出せる。
  ほかの人は同じ枚数を出し、同じ形でいちばん大きい数字が勝ち。同じ数字なら先に出した方
- マストフォロー（1枚と連番のリードには、そのスートを持っているだけ含める）、切り札なし
- 能力：商人＝仲買（取れなかったとき残った貨幣の最小1枚）／
  預言者＝預言（1人を指名して伏せて1枚ずつやりとり。相手がゴリラ札を持っていれば必ずそれを渡す。指名した人が取れば残りから1枚）／
  指導者＝徴税（取ったら残りからもう1枚）／王＝先導（王がいれば王がリードする）
- バナナ4枚（組の足りない1枚の代わり）とゴリラ札1枚（ゴリラ役が出せば必ず勝つ）を入れる（仕様 v0.9）
- 得点札はゲームに戻らない。手に残った札は次の局へ持ち越し、8枚まで補充。手札が尽きたら局を早く終える。5局で終わり

アプリでは、徴税と預言の「好きな1枚」はいちばん大きい札を自動で取る。

## CPUの思考

各候補札について「勝ったときの取り分」「勝っている人の点を消す価値」「先の役割のために札を残す価値」
「負けたときに相手へ渡る点」を足し合わせ、最大のものを出す。

- 対戦相手は all-in-texas の `PERSONAS` と同じ5人。`tight`＝札を残す度合い、`aggr`＝ゴリラを止めに行く強さ・預言で自分を指名する度合い、
  `bluff`＝乱れの大きさ
- むずかしさ：やさしい（ぶれが大きく、勝てる札に「勝」の印が出る）／ふつう／
  むずかしい（出た札と得点札から、見えていない強い札の数を読んで抜かれる危険を見積もる。王のときはゴリラより後の人に強い札を回すこともある）
