# 商人・預言者・ゴリラ・王 — ゴリラは本当に歴史を動かすのか

*Profits, Prophets, Gorillas, and Kings: (When) Do Gorillas Matter?*

ゴリラは本当に歴史を動かすのか。

王・商人・預言者・ゴリラの4つの役割が場ごとに隣の席へ回り、札を重ねて最後に出した人が場を総取りする、
2〜4人用（あなた＋CPU）のカードゲーム。
ブラウザだけで動く（ビルドなし、外部依存はGoogle Fontsのみ、通信なし）。

**あそぶ → https://pikaring.github.io/when-do-gorillas-matter/** （公開後）

題はジャレド・ダイアモンド『商人・預言者・指導者・王 リーダーは本当に歴史を動かすのか』
（土方奈美 訳、日経BP。原題 *Profits, Prophets, Coaches, and Kings: (When) Do Leaders Matter?*）のもじり。
副題の「リーダー」を「ゴリラ」に、原題の Leaders を Gorillas に差し替えた。
リポジトリ名の `(When)` は、ゴリラが1局に1回、自分の番にしか力を持たないことにかけている。
「第三のチンパンジー → 第三のゴリラ」「銃・病原菌・鉄 → 銃・病原菌・ダイヤモンド」に続くシリーズ3作目。
ルールはオリジナル。

## ルールの要点（v1.6）

くわしくは [`SPEC.md`](SPEC.md)（第1〜6節がルール、第10節が印刷）。

- 2〜4人・約30分（アプリなら15分以内）。役割は **王・商人・預言者・ゴリラ** の4つで、場が終わるたびに時計回りに隣へ移る（だれもが王→商人→預言者→ゴリラの順。預言者の次はゴリラ）。1局は4つの場、4局で終わり
- 数字札は4スート（貨幣・聖典・冠・ゴリラ）× 1〜13 × 2枚。2人は1〜9、3人は1〜11を使う。ほかにバナナ4枚、シルバーバック1枚
- 出す順は **王→商人→預言者→ゴリラ**（空席は飛ばす）。王がリード（1枚・連番・同数。バナナは同数の足りない1枚の代わり。連番には使えない）
- 以降は順にぐるぐる回り、同じ形・同じ枚数で **同じ色の上の数字** か **同じ数字**（色は問わない。同じ色の2枚目でもよい）を重ねるか、パスして抜ける。**同数は色を問わず、数字が上なら重ねられる**。連番も色を問わず上げられる。1枚を色を問わず上げられるのはゴリラだけ。いちばん大きい数字（4人なら13）の上には1を出せる（1周。1枚は同じスートの1〔ゴリラはどの色でも〕、同数は色を問わず、連番は 12・13 の上に 1・2 のように1から始まる連番）。同数は同じ数字の同数も重ねられる
- **最後に出した人が場の札を総取り**（役割に関係なく全部点）。得点札はゲームに戻らない。手札は場ごとに8枚まで補充
- 能力：王＝先導（リード）／預言者＝自分以外の1人を名指し、シルバーバック（なければいちばん大きい数字の札）を受け取って別の1枚を返す／
  商人＝取れなかったら先に貨幣の最大1枚／ゴリラ＝色を問わず上げられる、シルバーバックで場を即座に取り、ほかの全員から得点札のゴリラ札のいちばん大きい1枚をもらう（群れを率いる）。使ったシルバーバックは山札に戻る

## CPUの思考

場の点の大きさと、重ねるのに使う札を手元に残す価値を比べて、重ねるかパスかを決める。
重ねるときは、重ねられる出し方のうちいちばん安いものを出す。

- 対戦相手は all-in-texas の `PERSONAS` と同じ5人。`tight`＝札を残す度合い、`aggr`＝場を取りに重ねる強さ、`bluff`＝乱れの大きさ
- シルバーバックは、自分のゴリラの番が残っていれば抱え、その番に場が大きくなったら出す。預言でシルバーバックの行方を知ったら覚えておき、奪いに行く
- 預言者は、シルバーバックの持ち主を知らなければ、場を取りそうなゴリラを指名しがち
- むずかしさ：やさしい（重ねられる札に「可」の印が出る）／ふつう／むずかしい（場が小さいうちは強い札を温存する）

`app/index.html?debug` で開くと、`window.__mplg()` でゲームの状態を外から読める（自動テスト用）。
