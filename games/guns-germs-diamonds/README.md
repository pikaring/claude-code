# 銃・病原菌・ダイヤモンド（ブラウザ版）

以前サークル「鷹巣堂」で制作・頒布していたアナログカードゲーム
**「銃・病原菌・ダイヤモンド」**（ゲームマーケット2020春 出展）を、
ブラウザだけで遊べるHTML/JavaScriptゲームとして復刻したものです。

- 紹介ページ: [`index.html`](./index.html)（原作の紹介・ルール概要・あそぶボタン）
- ゲーム本体: [`app/index.html`](./app/index.html)（実際にプレイする画面）

どちらもビルド不要・外部ライブラリ不要で、ブラウザで直接開くだけで動作します。
`pikaring/cat-on-escape` などと同じく、紹介ページ（`/`）とゲーム本体（`/app/`）を分ける構成にしています。

- 対応モード:
  - 🧠 CPU対戦（1人プレイ）
  - 🤝 2人対戦（同じ端末を交代して使う「パス&プレイ」方式。相手の番の前に画面が隠れます）

## ルール（本ブラウザ版での実装）

2人対戦のカードゲームです。お互い同じ手札 `0`〜`4` を1枚ずつ（計5枚）持ちます。

| カード | 名称 | 強さ |
|---|---|---|
| 0 | 病原菌 | 1（偵察兵）以外の全カードと引き分け。1には負ける。 |
| 1 | 偵察兵 | 病原菌（0）には勝つが、2〜4の兵士には負ける。 |
| 2〜4 | 兵士 | 数字が大きい方が勝ち。同数は引き分け。 |

- 場には産出量（ダイヤモンド数）の異なる5つの鉱山が、常に **左から1・2・3・4・5💎の順** で並びます。
- 各ラウンドの開始時、両者は手札を **0〜4にリセット** します。
- 手札のカードをクリックすると、まだ決着していない鉱山のうち **一番左の空いている場所** へ自動的に配置されます。
  （置きなおしたいときは、配置済みの自分のカードが乗った鉱山をクリックすると手札に戻せます。）
- 自分が置いたカードは、配置中も伏せずに数字が見えたままです（相手のカードだけ「？」で隠れます）。
- 配置が終わったら鉱山を左から順にオープンし、強いカードを出した方がその鉱山のダイヤモンドを獲得します。
- **引き分けた鉱山は次ラウンドへ持ち越され**、ダイヤモンドの山がさらに積み増しされます。
- ゲームは全3ラウンド。最終ラウンドでも決着しなかった鉱山のダイヤモンドは、
  どちらの手にも渡らず失われます。
- 3ラウンド終了時（または全鉱山が決着した時点）で、獲得ダイヤモンド合計が多い方の勝ちです。

## 実装メモ

- `app/index.html` に HTML / CSS / JavaScript をすべて内包しており、外部依存はありません。
- CPU対戦のAIは、盤面の残りダイヤモンド量を見ながら手札を割り振る簡易ヒューリスティックです
  （最適戦略の実装ではなく、カジュアルに遊べる強さを狙っています）。
- 2人対戦（パス&プレイ）では、自分の番の配置が終わると全画面カバーが表示され、
  相手に配置内容が見えないようになっています。配置中も、今まさに手番のプレイヤーの
  カードだけが見えるようになっています（もう一方はまだ「？」のまま）。

## 今後の余地

`cat-on-escape` のように専用リポジトリ＋GitHub Pagesで公開する場合は、
別リポジトリを新設して同じ `index.html`（紹介ページ）／`app/index.html`（ゲーム本体）構成を
そのまま移設できます。本リポジトリ内ではGitHub Pagesの設定やアクセス解析などの外部連携は
行っていません。
