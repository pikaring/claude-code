# 第三のゴリラ — 2人用CPU対戦版

磯野貴巨氏のカードゲーム「第三のゴリラ」（ゲームマーケット2020春）を、
ブラウザで遊べる2人用CPU対戦に仕立て直したもの。

原作：https://isonotakami.hatenadiary.jp/archive/category/第三のゴリラ

`index.html` 単体で完結する（外部依存はGoogle Fontsのみ）。ブラウザで開けば遊べる。

## 原作から引き継いだ核

- 4色 × 9枚 = 36枚。数字は「ゴリラから人類へ至る進歩の段階」を表す
- 同色でより大きい数字、または色を問わず同じ数字を出す（ページワン型）
- **ゴリラ** — 出せるカードが1枚もないときだけ、どんな場にも出せる切り札。
  出した瞬間に全員が「ゴリラ！」と叫び、最も遅い者が場の捨札を引き取る
- **偽物のゴリラ** — 見た目はゴリラだが正体は数字6。場が同色の5以下のときだけ出せる。
  釣られた者は、出した側がそれまでに引き取った札をすべて背負う
- **現生人類（9）** — 次の手番は何を出してもよい（ゴリラを除く）
- 手札がゴリラだけになったらラウンド終了。引き取りが多い方が負け

## 2人用へのアレンジ

| 項目 | 内容 |
| --- | --- |
| 色の意味 | 4つの大陸（アフリカ／ユーラシア／アメリカ／オセアニア）。同色＝進歩、同数字＝他大陸への伝播 |
| 数字の意味 | 1 樹上のサル／2 火のボノボ／3 直立二足歩行／4 石器／5 狩猟採集／6 言語／7 農耕／8 文字と都市／9 現生人類 |
| 手札 | 各9枚 ＋ ゴリラ1枚 ＋ 偽物のゴリラ1枚。山札18枚 |
| 先攻 | 火のボノボ（第2段）を持つ側 |
| 掛け声 | 画面上の「ゴリラ！」ボタン（Space可）の反応時間勝負。出した本人も叫ぶ必要がある |
| 追加ルール | 偽物のゴリラを**見破られた**ら、出した側が場の捨札を引き取る。これがないとブラフが無リスクになり成立しないため |
| 試合形式 | 3ラウンド制。引き取り合計が少ない方の勝ち |
| 難易度 | やさしい／ふつう／ゴリラ級。CPUの反応時間・見極め精度・ブラフ頻度が変わる |

## CPUの思考

- **カード選択** — 現生人類（9）は相手に自由を与えるため減点。高い段を優先し、手札に多い大陸へ居座る。孤立した色は早めに処理
- **ブラフ** — 自分の引き取り札が多く、場の捨札が薄いときほど偽物を出す旨味が大きいと判断する
- **見極め** — まず「直前の場が同じ大陸の5以下だったか」を確認する。そうでなければ偽物はそもそも出せないので必ず叫ぶ。
  条件を満たす場合は難易度依存の確率で正解を見抜き、外したときは相手の引き取り枚数と場の厚さから推理する
- **切り札のタイミング** — 場の捨札が薄いうち、または山札が尽きたときにゴリラを切りたがる
