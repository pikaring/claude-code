どんなゲーム

4匹そろうと、走って逃げる。

よくある「3つそろえ」ではなく、4匹そろえ。 そろった ねこは その場で消えるのではなく、ぎょうれつを つくって 画面の 右へ 走りぬけます。

01

ねこの顔だけを ならべる

マスいっぱいに 顔を 大きく 出すので、小さい画面でも どの ねこか ひと目で わかります。

  • 4しゅるい（やさしい）／5しゅるい（むずかしい）を 切りかえ
  • 選んだ ねこは オレンジの わくで はっきり表示
02

逃げる → 落ちる → 連鎖

ねこが 走って いる あいだに 上から 新しい ねこが 落ちてきます。落ちた先で また そろえば 連鎖で 得点が 倍々に。

  • 連鎖は 画面まんなかに 大きく表示
  • 5匹以上 そろえると ボーナス
03

おおきな文字・おおきなボタン

前作 Tap on NEKO と 同じ 見やすさの つくり。高コントラストで、押すところは すべて 48px 以上です。

  • ひらがな中心の わかち書き
  • ねこが「〜ニャ」と 今の ようすを 教えてくれます
04

やめどきが 自由

制限時間も ゲームオーバーも ありません。手が なくなったら ねこたちが 自動で ならびなおします。

  • 最高得点と 設定は この端末の中だけに 保存
  • いつ やめても、いつ 始めても だいじょうぶ

あそびかた

となりと いれかえるだけ。

1ねこを となりの マスへ ドラッグする（タップ2回でも いれかえられます）
2タテか ヨコに 同じ ねこが 4匹そろうと、走って 画面の 右へ 逃げていく
3あいた ところに 上から 新しい ねこが 落ちてくる。そろえば そのまま 連鎖
4そろわない いれかえは 元に もどります（手数は ふえません）

パソコンでは マウスの ドラッグ、スマホ・タブレットでは 指で すべらせて あそべます。

つくり

HTML / CSS / JavaScript だけ。

フレームワークも ビルドも 使っていません。app/index.html を 開けば そのまま 動きます。 猫の絵は あとから 差しかえられるように、1か所に まとめてあります。

絵の 差しかえ口main.js の CAT_TYPES に 画像の パスを 書くだけ。読みこめない ときは 暫定の 丸のままで あそべます。
保存最高得点と 設定は LocalStorage に。サーバーには 何も 送りません。
画面サイズマスの 大きさは 画面に あわせて 自動計算。横向きでも スクロールなしで 収まります。
動きが 苦手な 方へprefers-reduced-motion に 対応。アニメーションを 切って あそべます。

よくある質問

気になるところ

お金は かかりますか？

かかりません。無料で、広告も 課金も ありません。

インストールは 必要ですか？

不要です。ブラウザで開くだけ。ホーム画面に追加すると、アプリのように 全画面で 開けます。

データは どこかに 送られますか？

送られません。最高得点も 設定も、お使いの端末の中だけに 保存されます。

猫の絵が 丸なのは なぜ？

絵を 用意するまでの 暫定表示です。画像を app/images/ に置いて CAT_TYPES に パスを書くと、そのまま 猫の顔に なります。
