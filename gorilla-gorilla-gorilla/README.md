# 若い類人猿のための第三のゴリラ

2人用CPU対戦・ドンジャラ式。題はジャレド・ダイアモンド『若い読者のための
第三のチンパンジー』のもじり。ディレクトリ名の gorilla-gorilla-gorilla は
ニシゴリラの学名 *Gorilla gorilla gorilla* から。

「第三のゴリラ」の世界観（人類の進歩とゴリラ）を、ドンジャラ／ジンラミー型の
集め役ゲームに組み直した2人用CPU対戦。`index.html` 単体で動く。

`../third-gorilla/` のページワン型とは別ゲーム。遊び比べ用に並べて置いている。

## 札 — 38枚

4大陸（アフリカ／ユーラシア／アメリカ／オセアニア）× 9段階 = 36枚、
＋ レインボーゴリラ 2枚。

| 段 | 名 | |
| --- | --- | --- |
| 1 | 樹上のサル | |
| 2 | 火のボノボ | |
| 3 | 直立二足歩行 | |
| 4 | 石器 | |
| **5** | **ゴリラ** | 罰10点 |
| 6 | 言語 | |
| 7 | 農耕 | |
| 8 | 文字と都市 | |
| 9 | 現生人類 | |

**進歩の道の真ん中、第5段にゴリラが座っている。** 系譜は1大陸につき7通りあるが、
そのうち 3-4-5 / 4-5-6 / 5-6-7 の3通りはゴリラを通らないと繋がらない。
つまり中盤の進歩を扱うには罰10点を抱える必要がある。5の伝播（3色のゴリラ）は
抱え込みで30点。テーマがそのまま確率構造になっている。

## 組

- **系譜** — 同じ大陸の連続する3段階（アフリカ 3-4-5）
- **伝播** — 異なる3大陸の同じ段階（7が3色）

手の内は9枚。**3組9枚で上がり**。麻雀と違って頭は不要（3組なら9枚で割り切れる）。

## 手番

山札か捨て札の一番上か、どちらかから1枚引いて1枚捨てる。ポン・チーなし。

- **捨て札を拾った手番は山札が減らない** → 拾うほど局が延びる
- 2人なので、自分の手番の捨て札は必ず相手が直前に捨てた札。
  **それを拾って上がれば実質のロン** ＝「ゴリラ！」。山札からなら「ツモ」
- 山札が尽きたら強制精算（拾い合いで無限に回るのを防ぐ）

## 公開（副露）

揃った組は自分の手番に公開できる。**公開した組は精算で0点**、伏せたままだと札の点が
そのまま失点。

では常に公開すべきかというとそうではない。公開は手の内を相手に教える——残り何組かが
見えるので相手は危険牌を止め、こちらの上がりは遠のく。
**公開の唯一の利点は「相手に先に上がられたときの保険」**。相手が近づいたと見たら公開し、
まだ遠いなら伏せて粘る。

**レインボーゴリラを使った組は上がるまで公開できない。**組は一気に埋まるが、上がれなければ
その3枚は必ず失点として残る勝負手専用の札。1組につき1枚まで。

## 精算

- 上がられた側は伏せ札の合計点を相手に献上
- 流局は伏せ札の少ない方がその差を得点
- 先に100点で勝ち

## CPUの思考

- **組の分解** — 手の内を「最大数の組 → 最小の失点」で全探索して分解する（`bestPartition`）。
  レインボーは1組1枚までの代替として候補生成に混ぜる
- **拾うか引くか** — 拾った場合の評価値（失点 − あと1枚で組になる形への含み益）が
  一定以上改善するときだけ拾う。拾えば即上がりなら必ず拾う
- **公開の判断** — 相手の公開組数、山札の残り、相手が捨て札を拾った回数から
  「先に上がられるリスク」を見積もり、閾値を超えたら公開する
- **捨て札の危険度** — 相手が拾った札と同色±2段／同段の札、およびゴリラを危険とみなす。
  相手が残り1組のときは全体の危険度を底上げする。難易度でこの重みと乱雑さが変わる
