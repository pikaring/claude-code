# ネコおち（ねこの おちもの パズル）

ブラウザだけで動く、猫の落ちものパズルです。ビルド不要・依存ライブラリなし・通信なし。
`cat-puzzle/index.html` をブラウザで開けば遊べます（`file://` のままでも動作します）。

画面のつくりは前作 **[Tap on NEKO（ねこの ともだち）](https://pikaring.github.io/tap-on-neko/)** に合わせてあります。

```
cat-puzzle/
├── index.html   画面（ヘッダー／ばん／おおきなボタン／モーダル）
├── style.css    見た目（前作と同じ色・ボタン・モーダル。猫の暫定アートもここ）
├── game.js      ゲームロジック
└── assets/      猫の画像置き場（今は空）
```

## 前作から引き継いだUI

- 色：濃い緑のヘッダー `#2f5d3a` ／ クリームの地 `#fff8ec` ／ 黄色の数字 `#ffe36e`
- 大きい文字（`clamp()` で画面幅に追従）、太字、高コントラスト
- 下部の大きなボタンは立体的（押すと沈む）、タップ領域は48px以上
- 白い角丸パネルのメッセージ欄で、猫が「〜ニャ」と状況を伝える
- 設定は前作の「どの ねこに する？」と同じモーダル（`.modal__panel` / `.cat-choice`）
- ひらがな中心の分かち書き、`overflow: hidden` でページはスクロールしない
- 画像が読み込めないときは暫定表示のまま遊べるフォールバック設計
- 横向き・背の低い画面向けのメディアクエリ、`prefers-reduced-motion` 対応

## 遊びかた

- 隣り合う猫をドラッグ、またはタップ2回で入れかえます。
- タテかヨコに同じ猫が **4匹** そろうと、猫たちが走って画面外へ逃げます。
- 空いたマスには上から新しい猫が降ってきます。落ちてきた猫がまたそろうと連鎖になり、得点が倍々になります（「2れんさ！」と大きく表示）。
- そろわない入れかえは元に戻ります（手数は増えません）。
- 入れかえる手がなくなったら、猫たちが自動で並びなおします。
- 最高得点と「ねこの かず」の設定は `localStorage`（`nekoochi.best` / `nekoochi.kinds`）に保存されます。

得点は `逃げた猫の数 × 10 ＋ 5匹以上そろった分のボーナス` に連鎖数を掛けた値です。

## 猫の絵の差し替え（Gemini で作った画像を入れるとき）

暫定アートは丸で描いているだけなので、画像ができたら2ステップで差し替えられます。

1. 画像を `cat-puzzle/assets/` に置く（正方形・背景透過のPNG推奨、目安 512×512px）。
2. `game.js` 冒頭の `CAT_TYPES` の `image` にパスを書く。

```js
const CAT_TYPES = [
  { key: 'kuro',      name: 'くろねこ', image: 'assets/cat-kuro.png' },
  { key: 'chashiro',  name: 'ちゃしろ', image: 'assets/cat-chashiro.png' },
  { key: 'kijitora',  name: 'キジトラ', image: 'assets/cat-kijitora.png' },
  { key: 'hachiware', name: 'ハチワレ', image: 'assets/cat-hachiware.png' },
  { key: 'mike',      name: 'みけねこ', image: 'assets/cat-mike.png' },
];
```

- 画像は読み込みに成功したときだけ使われます。パスを間違えても、その種類だけ丸のまま遊べます（前作と同じ考えかた）。
- 1種類ずつ順に差し替えても崩れません。
- **前作の3×3スプライトシートをそのまま使う場合**は `sheet: true` を足すと、左上（おすわり）のコマだけを表示します。
  `{ key: 'kuro', name: 'くろねこ', image: 'assets/cat-kuro.png', sheet: true }`
  種類名（`key`）は前作の猫に合わせてあるので、`tap-on-neko/app/images/cat-*.png` をコピーすればそのまま猫の絵になります（動作確認済み）。

画像生成のプロンプト例（Gemini 向け・前作の画風に合わせる場合）:

> 正方形・背景透過のかわいい猫アイコンを1匹。フラットなベタ塗りのアニメ・絵本調、こい茶色の太い輪郭線、影やグラデーションは最小限、大きな黒目のデフォルメ2頭身。正面を向いておすわりして、にっこり笑っている。首輪なし、小物なし。まわりに10%ほどの余白。毛色は「くろねこ」。同じ画風・同じ大きさで毛色ちがいを5種類（くろ・ちゃしろ・キジトラ・ハチワレ・みけ）。

前作の `docs/cat-sprite-prompt.md` のプロンプトもそのまま使えます（その場合は `sheet: true`）。

## 調整できるところ

`game.js` の冒頭にまとまっています。

| 定数 | 既定値 | 意味 |
| --- | --- | --- |
| `COLS` / `ROWS` | 7 / 8 | 盤面の列数・行数 |
| `MIN_MATCH` | 4 | 何匹そろったら逃げるか |
| `SWAP_MS` / `FALL_MS` / `FLEE_MS` | 170 / 260 / 520 | 入れかえ・落下・逃走のアニメ時間（ms） |

アニメ時間は `style.css` の `--swap-ms` / `--fall-ms` / `--flee-ms` と対になっているので、変えるときは両方そろえてください。
猫の種類数は画面の「ねこの かず」ボタンから4種類／5種類を切り替えられます（5種類のほうがそろいにくく難しめ）。
