# ネコおち（猫の落ちものパズル）

ブラウザだけで動く、猫の落ちものパズルです。ビルド不要・依存ライブラリなし。
`cat-puzzle/index.html` をブラウザで開けば遊べます（`file://` のままでも動作します）。

```
cat-puzzle/
├── index.html   画面
├── style.css    見た目（猫の暫定アート＝黒丸・白丸もここ）
├── game.js      ゲームロジック
└── assets/      猫の画像置き場（今は空）
```

## 遊びかた

- 隣り合う猫をドラッグ、またはタップ2回で入れかえます。
- タテかヨコに同じ猫が **4匹** そろうと、猫たちが走って画面外へ逃げます。
- 空いたマスには上から新しい猫が降ってきます。落ちてきた猫がまたそろうと連鎖になり、得点が倍々になります。
- そろわない入れかえは元に戻ります（手数は増えません）。
- 入れかえる手がなくなったら、猫たちが自動で並びなおします。
- 最高得点は `localStorage`（キー: `nekoochi.best`）に保存されます。

得点は `逃げた猫の数 × 10 ＋ 5匹以上そろった分のボーナス` に連鎖数を掛けた値です。

## 猫の絵の差し替え（Gemini で作った画像を入れるとき）

暫定アートは丸で描いているだけなので、画像ができたら2ステップで差し替えられます。

1. 画像を `cat-puzzle/assets/` に置く（正方形・背景透過のPNG推奨、目安 256×256px）。
2. `game.js` 冒頭の `CAT_TYPES` の `image` にパスを書く。

```js
const CAT_TYPES = [
  { key: 'kuro',  name: '黒猫',   image: 'assets/cat-kuro.png' },
  { key: 'shiro', name: '白猫',   image: 'assets/cat-shiro.png' },
  { key: 'hai',   name: '灰猫',   image: 'assets/cat-hai.png' },
  { key: 'buchi', name: 'ぶち猫', image: 'assets/cat-buchi.png' },
  { key: 'tora',  name: 'とら猫', image: 'assets/cat-tora.png' },
];
```

`image` が入ると `.cat__body--image` が付き、丸の塗りと枠は自動的に消えます。
`image: null` のままの種類は今までどおり丸で表示されるので、1種類ずつ差し替えていくこともできます。

画像生成のプロンプト例（Gemini 向け）:

> 正方形・背景透過のかわいい猫アイコン。真上から見た丸いシルエット、フラットイラスト、影なし、余白すこし。種類は「黒猫」。同じ画風で色違いを5種類（黒・白・灰・ぶち・とら）。

## 調整できるところ

`game.js` の冒頭にまとまっています。

| 定数 | 既定値 | 意味 |
| --- | --- | --- |
| `COLS` / `ROWS` | 7 / 8 | 盤面の列数・行数 |
| `MIN_MATCH` | 4 | 何匹そろったら逃げるか |
| `SWAP_MS` / `FALL_MS` / `FLEE_MS` | 170 / 260 / 520 | 入れかえ・落下・逃走のアニメ時間（ms） |

アニメ時間は `style.css` の `--swap-ms` / `--fall-ms` / `--flee-ms` と対になっているので、変えるときは両方そろえてください。
猫の種類数は画面の「猫の種類」セレクトで4種類／5種類を切り替えられます（5種類のほうがそろいにくく難しめ）。
