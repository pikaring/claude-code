# 三人麻雀（サンマ）

ブラウザだけで動く、軽量な三人麻雀ゲームです。
`index.html` をブラウザで開くだけで遊べます。ビルド不要・依存ライブラリなし・通信なしで、
ファイルをローカルに置いたまま（`file://`）でも、静的ホスティングに置いても動きます。

```
sanma/
├── index.html        ゲーム本体（これを開く）
├── standalone.html   1ファイル版（build.js が生成。単体で配布できる）
├── build.js          index.html に CSS/JS を埋め込むビルドスクリプト
├── css/style.css
├── js/
│   ├── tiles.js      牌の定義・山・ドラ・表記
│   ├── hand.js       シャンテン数・和了判定・待ち・受け入れ
│   ├── yaku.js       役判定・符計算・点数計算
│   ├── ai.js         CPU の思考ルーチン
│   ├── game.js       局進行のステートマシン
│   └── ui.js         描画と操作
└── tests/
    ├── test.html     ブラウザで開くセルフテスト
    └── run.js        `node tests/run.js` でも実行可能
```

1 ファイルだけ配りたいときは `standalone.html` を使ってください（約 90 KB）。
ソースを編集したあとは `node build.js` で作り直します。

## 遊び方

1. `sanma/index.html` をブラウザで開く（ダブルクリックで OK）。
2. 自分の番になったら、手牌をクリックして打牌します。
3. リーチは「リーチ」ボタンを押してから、捨てる牌を選びます。
   リーチ後は自動でツモ切りされます（ツモ和了・暗カン・北抜きができるときだけ止まります。
   待たずに切りたいときは牌をクリックしてください）。
4. ポン・カン・ロンは、鳴ける場面でボタンが出たときに選びます（不要なら「パス」）。

画面上部のボタン:

| ボタン | 内容 |
| --- | --- |
| 敵 | CPU の強さ（やさしい／ふつう／つよい） |
| ヒント | 自分の手牌のシャンテン数／待ちと残り枚数を表示 |
| 速度 | CPU の打牌速度（遅／普／速／瞬） |
| 新規 | 最初からやり直す |
| ルール | 採用ルールの一覧 |

## 画面

iPhone Air（CSS ピクセルで 420 × 912）を基準にした固定レイアウトです。
捨て牌や副露が増えても他の要素がずれないよう、各段の高さは中身ではなく
牌の寸法から決めています。

```
操作ボタン
局情報（局 / 残り / 供託 / ドラ表示牌）
下家（手牌 1 段・副露 + 抜きドラ 1 段・河 2 段）
上家（同上）
ログ（余った高さを吸収）
自分の河 2 段
自分の副露 + 抜きドラ 1 段
自分の手牌 1 段（14 枚が必ず 1 列に収まる）
コマンド（最下段に固定）
```

上家・下家は横並びにせず縦に積んで全幅を使うので、河・副露・伏せ牌はすべて自分と同じ寸法です。
並び順は手番の流れどおり（自分 → 下家 → 上家 → 自分）で、直前に打つ上家が手牌のすぐ上に来ます。

牌の寸法は盤面の幅から計算しているので、画面幅が変わっても手牌は 1 列のままです。
縦に余裕がない端末では牌を段階的に小さくして 1 画面に収めます
（420×912 / 393×852 / 390×668 / 360×640 / デスクトップで、スクロールなしを確認済み）。
河が 2 段を超えた場合だけ、その枠の中だけがスクロールします（レイアウトは動きません）。

### 河の見方

| 見た目 | 意味 |
| --- | --- |
| 明るい牌面 | 手出し（手牌から選んで切った牌） |
| 沈んだ牌面 | ツモ切り（引いてきた牌をそのまま切った牌） |
| 赤枠 | リーチ宣言牌 |
| 薄い牌 | 鳴かれた牌 |

手出しのほうが多い（実測で約 7 割）ので、少数派のツモ切り側に印を付けて河が騒がしくならない
ようにしています。鳴かれた牌も河に残すので、フリテン判定や現物読みの材料はそのまま残ります。

## 採用ルール

**基本**

- 使用牌は 108 枚。萬子は**一萬と九萬のみ**（二萬〜八萬を抜く）。
- 赤ドラは赤五筒・赤五索が各 1 枚（三麻に五萬は無いので 2 枚構成）。
- 東風戦（東 1 局〜東 3 局）、持ち点 35000 点、親の連荘あり。
- 誰かの持ち点が 0 点未満になった時点で終了（飛び）。

**鳴き・進行**

- **チーなし**。ポン・暗槓・加槓・大明槓は可能。
- **北は抜きドラ**。自分の番に抜くと嶺上牌をツモり、抜いた 1 枚につき 1 翻のドラになります。
  抜かずに手牌で使ってもかまいませんが、その場合は客風なので役にはなりません。
  - 抜いても鳴きにはならないため、門前・一発・ダブリーの条件は崩れません。
  - 抜いた北は搶槓の対象です（他家はその北でロンできます）。
  - カンではないので新ドラはめくれず、抜いた直後のツモ和了も嶺上開花にはなりません。
- ダブロンなし。放銃者から見て順番が近い方が優先（頭ハネ）。
- カンドラは槓の成立時に即めくり。裏ドラはリーチ時のみ、カンドラと同じ枚数。
- 一発・フリテン（同巡内／リーチ後の永続）・槍槓・嶺上開花・海底／河底に対応。

**点数**

- **ツモ損あり**。子のツモは「親 2 : 子 1」の 3 倍取り、親のツモは「子 2 × 2」の 4 倍取り。
- 流局時は 3000 点を分配（1 人テンパイなら +3000／ノーテン -1500 ずつ、2 人テンパイなら
  +1500 ずつ／ノーテン -3000）。
- 数え役満あり、切り上げ満貫なし。役満の複合は倍役満まで（四暗刻単騎・国士十三面・大四喜）。

**未実装**

九種九牌・四風連打・四家立直などの途中流局、および九蓮宝燈・流し満貫は入っていません。

## CPU の思考

打牌は次の式で評価します。α・β・γ はキャラクターごとの重みです。

```
評価 = -シャンテン数 * (500 + 500 * α速度)
     + 受け入れ枚数 * 8 * α速度        ← 場に見えていない残り枚数で加重
     + 打点期待値 * β打点              ← ドラ・赤・抜きドラ・役牌・染め手
     - 危険度 * 2 * γ守備              ← 他家リーチに対する無筋の危険度
```

シャンテン数の重みも α に連動させているので、打点型は手を進めるよりドラや染め手の形を
残すことを選び、速攻型は形を崩してでも手を進めます。リーチ判断では、リーチを打たなかった
場合の翻数を実際に `evaluate()` で見積もって、ダマに構えるかどうかを決めています。

### 対戦相手（キャラクター）

半荘ごとに、5 人の打ち筋から 2 人が重複なくランダムで選ばれます。

| | α速度 | β打点 | γ守備 | 副露基準 | リーチ | オリ移行 |
| --- | --- | --- | --- | --- | --- | --- |
| ①デジタル | 1.0 | 1.0 | 1.0 | 1翻確定以上 | ほぼ即リー | 無筋2枚以上でノーテン時 |
| ②猛牛 | 1.2 | 1.1 | 0.3 | 緩め | 即リー | ほぼしない（テンパイなら全押し） |
| ③岩 | 0.9 | 0.6 | 2.5 | 役牌のみ | 打点条件付き | 他家リーチで即ベタオリ |
| ④鳶 | 1.8 | 0.2 | 0.8 | 2向聴から鳴く | ダマ多め | テンパイ以外は降りる |
| ⑤龍 | 0.4 | 2.5 | 0.9 | 染め手のみ | 打点足りればダマ | 手役崩壊時のみ |

各キャラをデジタル 2 人と 600 局戦わせた実測値です。太字が、そのキャラの看板にあたる数字。

| | 和了率 | 放銃率 | 平均打点 | 満貫率 | リーチ率 | 副露率 | 流局時テンパイ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| デジタル | 25.3% | 14.6% | 8838 | 61% | 43% | 23% | 52% |
| 猛牛 | 29.2% | **22.5%** | 9265 | 63% | 37% | 39% | **76%** |
| 岩 | 22.1% | **10.7%** | 8459 | 63% | 31% | 22% | **32%** |
| 鳶 | 25.5% | 16.9% | **7170** | **47%** | **25%** | **48%** | 55% |
| 龍 | 29.8% | 19.1% | **9524** | **71%** | 39% | **11%** | 68% |

猛牛は最も放銃し最もテンパイまで押し、岩は最も放銃せず最も降り、鳶は最も鳴いて最も安く、
龍は最も鳴かずに最も高い、という形で看板どおりに分かれています。
`node tests/characters.js` で再測定できます。

### 難易度（腕前）

キャラクターとは別に、CPU の腕前を 3 段階で選べます。打ち筋が「どう打ちたいか」、
難易度が「それをどれだけ正確に実行できるか」です。

**CPU は他家の手牌・山・王牌・裏ドラを一切見ていません。** 参照しているのは自分の手牌と、
河・副露・ドラ表示牌という誰にでも見える情報だけです。`node tests/audit.js` を実行すると、
CPU の思考中にそれらへアクセスしたら例外を投げる状態で対局を回して検証できます。

| | 場の残り枚数を読む | ドラの見積もり | 打牌精度 |
| --- | --- | --- | --- |
| やさしい | 読まない | 甘い | 45% は次善手 |
| ふつう | 読む | やや甘い | 20% は次善手 |
| つよい | 読む | 正確 | 常に最善手（評価式の中で 1 位を選ぶ） |

「常に最善手」は評価式の中で 1 位の牌を選ぶという意味で、麻雀として最善という意味ではありません。

## テスト

牌の定義・シャンテン計算・役判定・符・点数についての自己テストが入っています。

```sh
node tests/run.js        # コンソールで実行
```

`tests/test.html` をブラウザで開いても同じテストが走ります。

シャンテン計算については、実装を差し替えても壊れていないことを確認できるよう、
総当たり版との突き合わせで検証しています（ランダム 6000 手牌で一致を確認済み）。
