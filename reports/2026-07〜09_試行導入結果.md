# 生成AI(Qommons AI)試行導入の結果と成果 2026年7月〜9月

函館市 総務部情報システム課

## 1. 概要

- 3か月で**職員713人が利用**し、利用率は69.6%から**76.0%**へ上がった。前月から翌月も使い続けた人の割合は**約9割**で、一時的な試用ではなく**日常業務に定着**した
- 質問件数は月26,604件から**32,266件**へ増えた(+21%)。標準的な前提(1件10分短縮)で**3か月計 約15,000時間・約1,950人日**の業務時間削減に相当する(推計)
- 用途は議会答弁、条例・規程の解釈、契約事務、資料作成など**正確性が求められる中核業務**に広がった
- 一方、9/17のベンダー側による Claude 系モデルの停止で利用が約3割減った。**モデルの選択肢と契約条件が、効果を左右する**ことも明らかになった

## 2. 利用実績

| 指標 | 7月 | 8月 | 9月 |
|---|---:|---:|---:|
| 質問件数(プロンプト数) | 26,604 | 31,621 | **32,266** |
| 総利用回数(質問+応答) | 52,897 | 62,820 | **64,191** |
| 利用者数 | 590人 | 658人 | **713人** |
| 登録者数 | 848人 | 910人 | 938人 |
| 利用率(利用者÷登録者) | 69.6% | 72.3% | **76.0%** |
| 利用があった部署数 | 143 | 149 | **151** |
| 平日1日平均(総利用回数) | — | 3,102件 | 3,308件 |

- 利用はほぼ平日の勤務時間内に集中しており、休日は1日100件前後にとどまる。**業務での利用**が中心である
- 9月は、前半(9/1〜9/17)が平日1日平均3,675件・281人と過去最高だった一方、Claude 系モデル停止後(9/18〜9/30)は2,512件・211人に下がった(後述)

## 3. 成果

### (1) 利用の定着

| | 7月→8月 | 8月→9月 |
|---|---:|---:|
| 前月の利用者のうち翌月も利用した割合 | 88.6% | **90.7%** |
| 新規利用者 | 135人 | 87人 |

- 前月に使った職員の約9割が翌月も使っている。導入初期の試用で終わらず、**業務の道具として使い続けられている**
- 上位10人が全質問に占める割合は 18.9%(7月)→13.5%(8月)→12.0%(9月)と下がり、**一部の詳しい職員に頼らない、裾野の広い利用**になった
- 上位部署は、情報システム課・市民・男女共同参画課・管路整備室・企画管理課・監査課など。利用率80〜100%で、**部署ぐるみで活用**されている

### (2) 業務削減効果(推計)

| | 7月 | 8月 | 9月 | 3か月計 |
|---|---:|---:|---:|---:|
| 質問件数 | 26,604 | 31,621 | 32,266 | 90,491 |
| 削減時間(1件10分) | 4,434時間 | 5,270時間 | 5,378時間 | **15,082時間** |
| 人日換算(7.75時間/日) | 572人日 | 680人日 | 694人日 | **1,946人日** |
| 人件費換算(3,000円/時) | 1,330万円 | 1,581万円 | 1,613万円 | **4,525万円** |

- 1件あたりの削減時間を5分と控えめに見積もっても、**3か月で約7,500時間・約970人日**になる
- 利用ログは「使った量」を示すもので、各質問が実際にどれだけ手作業を置き換えたかは判別できない。**推計値として扱う**必要がある。精度を上げるには、職員アンケートで「AIで何分短縮できたか」を実測し、1件あたりの削減時間を置き換える

### (3) 活用分野の広がり

8月・9月の質問内容を分類すると、上位は次のとおり。

| 分野 | 主な内容 |
|---|---|
| 政策文書・資料作成 | 説明資料のたたき台、会議資料・国の通知の要約、監査や条例制定に関する文書 |
| 条例・規程に基づく実務判断 | 工事約款、財産条例、給与条例、港湾施設管理条例など、条文を示して根拠を確認 |
| 議会対応 | 想定質問の洗い出し、答弁案の作成・校正、過去答弁の参照(9月定例会で利用が集中) |
| 契約・会計・人事 | 随意契約の要否、印紙税、時間外勤務の扱いなど |
| 対外文書 | 挨拶文、協議会の案内、催促・御礼メールの作成・添削 |
| 業務ツール開発 | Excel関数・マクロ、Google Apps Script による発注・集計用Webアプリ |

- 定型文の作成だけでなく、**条例解釈や議会答弁など、正確性が求められる中核業務**で使われている
- 職員が自分で業務ツールを作るといった、**導入前には想定していなかった使い方**も生まれている

### (4) 職員による使い分けの進展

- 8月にかけて、職員は精度の高いモデル(Claude Sonnet 4.6・Opus 4.8)を自分で選ぶようになり、その割合は36%(7月)から71%(8月)へ上がった
- 軽量モデルの利用はほぼなくなった。**業務内容に応じて職員が自分でモデルを選んでいる**ことの表れといえる

## 4. 見えてきた課題

| 課題 | 内容 |
|---|---|
| **ベンダー都合のモデル停止** | 9/17に無償プランを対象に Claude Opus・Sonnet が停止。停止前後の平日1日平均で**利用回数-32%、利用者-25%**。9月末時点で再開していない |
| **代替モデルの精度** | 停止を受けて Claude Haiku 4.5(軽量モデル)を開放したが、条例解釈・議会答弁・庁内文書検索など精度が求められる用途での利用が多い。10/5のコモンズ通信で使い分けを呼びかける予定 |
| **無償プランの1,000アカウント上限** | 登録者938人(10/1時点)。未利用アカウントの棚卸し(8月170人、9月43人)で枠内を維持している |
| **有償プランの利用量上限** | 有償プランでは標準・高性能モデルに月3億トークンの上限がかかる。現状の利用量で上限の約4〜6割と試算 |
| **ファイル出力機能がない** | Word・Excel 等のファイルを直接作れない。中間アンケートでも要望が多い |
| **利用ログ出力の不具合** | 10月から新しくなった管理画面の CSV に、件数の打ち切りと重複がある。ベンダーに改善を依頼中 |

## 5. 今後の方向性

1. **Qommons AI は全職員向けの基盤として来年度も継続する**。有償化(2,000アカウントで年12万円)で、モデル停止とアカウント上限の制約を解消する方向で、年内の移行を検討する
2. **AIエージェント機能を持つ新システムを、AI推進リーダー向けに導入する**(同時接続30名規模)。来春のプロポーザルで事業者を選定する。要件には、ファイル出力機能と、利用量・モデル停止に関する契約条件の明示を入れる
3. **効果測定の精度を上げる**。職員アンケートで実際の削減時間を把握し、上記の推計を実測値に置き換える
