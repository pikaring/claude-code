# オンタマ (Onitama) Webアプリ

React + TypeScript + Vite + Tailwind CSS で実装した、1画面完結のオンタマ対戦アプリ。

- 1人 vs CPU (ミニマックス法 + αβ枝刈り, 深さ3)
- 2人ローカル対戦(同じ画面で交互に操作)

## セットアップ

```sh
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド
npm run preview   # ビルドしたアプリをプレビュー
npm run lint      # oxlint
```

## 遊び方

1. 自分の手札(下段: Player 1, 上段: Player 2)からカードを1枚選ぶ。
2. 動かす自分の駒をクリックすると、そのカードで移動できるマスがハイライトされる。
3. ハイライトされたマスをクリックして移動。使用したカードは待機枠へ、待機カードが手札に加わる。
4. 相手のマスターを撃破する(石の道)か、自分のマスターが相手の拠点(⛩)に到達する(小川の道)と勝利。
5. 手札のどちらのカードでも駒を動かせない場合のみ、カードを選んでパスできる。
